# Dossiê de verificação independente — Parte III, III.11 e III.12

Instruções, roteiros por item e as páginas 69–82 do volume, para a verificação independente da lei de fase.

- `dossie.tex`: fonte do dossiê (28 páginas). Compile nesta pasta com `pdflatex dossie.tex` (duas vezes). Ele
  anexa as páginas 69–82 de `../../Biblioteca_Unificada.pdf`; se o volume for recompilado, confira a paginação.
- `verificador_independente.py`: verificador de `n_f(ε)` para `e^x`, só com `mpmath`; roda em cerca de 1 s.

O dossiê não faz parte das demonstrações do volume.
