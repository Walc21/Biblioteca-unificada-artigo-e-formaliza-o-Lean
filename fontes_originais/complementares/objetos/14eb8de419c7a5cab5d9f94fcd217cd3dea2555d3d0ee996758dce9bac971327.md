## Reproduzir o inventário

```bash
python3 scripts/mapear_corpus.py
python3 scripts/validar_pacotes.py --resumir
```

`enunciados.json` conserva o texto integral de cada ambiente, os rótulos, a posição e o hash do enunciado. `correspondencias_revisadas.json` é o mapa inspecionado; o script rejeita referências a nomes inexistentes no inventário Lean. Os arquivos `CorrespondenciasAudit.lean` conferem os nomes no compilador. Não foram alteradas hipóteses, assinaturas ou demonstrações para produzir este mapa.
