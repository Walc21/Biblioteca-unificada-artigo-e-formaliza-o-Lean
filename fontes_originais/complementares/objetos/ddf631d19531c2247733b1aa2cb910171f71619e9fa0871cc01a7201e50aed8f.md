# Etapa 1 — Biblioteca determinística / Aristotle

## Escopo
Fonte original: `Biblioteca_Deterministica_Fontes_LaTeX.zip`.
O arquivo `artigo_fase1.tex` é um excerto autocontido das seções 2 e 3,
com numeração preservada. O texto matemático das duas seções não foi alterado.

**Alvo prioritário:** Teorema 3.5 (unicidade do endereço / injetividade do gerador Γ).
**Dependências principais:** Lemas 2.1, 2.2, 2.4, 3.1, 3.2 e 3.4;
o Lema 2.4 usa o Lema 2.3. O Teorema 3.6 pode ser tratado depois.

## Para um agente executando na nuvem
1. Instalar/usar a versão corrente do SDK `aristotlelib` e confirmar
   a sintaxe CLI atual consultando a documentação oficial.
2. Autenticar **fora do repositório e do chat**, via segredo do ambiente
   `ARISTOTLE_API_KEY`. Não registrar a chave em logs ou arquivos.
3. Enviar `artigo_fase1.tex` para autoformalização.
   Exemplo documentado na versão 2.1.0 do SDK:
   `aristotle formalize artigo_fase1.tex --wait --destination resultado.tar.gz`
4. Validar o Lean gerado contra a versão de Lean e Mathlib do projeto
   retornado; conferir o elaborador, axiomas usados e ausência de `sorry`.
5. Comparar cada enunciado Lean com as hipóteses e conclusões do LaTeX.
   Um teorema formal simplificado não certifica automaticamente o enunciado original.
6. Registrar o status individual de 2.1, 2.2, 2.3, 2.4, 3.1, 3.2, 3.4,
   3.5 e 3.6: fiel/verificado, fiel/incompleto, divergente ou bloqueado.

O verificador `scripts/verificar.py` do ZIP original confere somente a
integridade editorial do artigo, não prova a correção matemática.
Este pacote ainda não foi submetido à API nem verificado em Lean.

## Observações sobre o material
O README do ZIP original registra que os fontes LaTeX foram reconstruídos
com base em um PDF. Portanto, use também o PDF de 30 páginas como referência
para verificar equivalência semântica durante a formalização.
A tentativa de compilação neste ambiente não prosseguiu porque a fonte
`Latin Modern Roman` não está registrada no sistema; isso não é uma falha
matemática, e nenhuma compilação Lean ou submissão Aristotle foi executada.
