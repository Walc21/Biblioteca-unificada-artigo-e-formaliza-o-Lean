# Biblioteca determinística de segmentos afins racionais em células diádicas

Fonte do artigo revisado de Victor Gabriel de Oliveira.

## Composição

Requisitos: Python 3.10 ou posterior; NumPy e Matplotlib; distribuição
TeX Live com XeLaTeX, latexmk, BibTeX, fontes Latin Modern, unicode-math, TikZ,
babel-portuguese, natbib e os pacotes usados no preâmbulo.

Em Debian/Ubuntu, os componentes TeX correspondem a latexmk, texlive-xetex,
texlive-lang-portuguese, texlive-latex-extra, texlive-science,
texlive-fonts-recommended e lmodern.

    python3 -m pip install -r requirements.txt
    bash compilar.sh

O PDF será criado como artigo.pdf. As figuras vetoriais já estão incluídas;
o comando python3 scripts/figuras.py permite regenerá-las. O diagrama final
está em figuras/circuito.tex e é composto diretamente pelo TikZ.

Para limpar os arquivos temporários de composição:

    latexmk -c artigo.tex

## Organização

- artigo.tex: preâmbulo e ordem de composição.
- secoes/: texto, fórmulas e demonstrações.
- referencias.bib: bibliografia do escopo mantido.
- figuras/: PDFs vetoriais e fonte TikZ do circuito.
- scripts/figuras.py: geração das figuras e dos dados que as sustentam.
- scripts/codigos.py: contagem exata dos formatos e reprodução da tabela 2.
- scripts/verificar.py: conferência das equações, dos enunciados e das referências.
- compilar.sh: geração das figuras, verificações e composição do PDF.

Os enunciados das seções 2–7 e as equações (1)–(95) mantêm sua numeração.
O bloco auxiliar original das seções 8–14 foi removido; a conclusão passou
a ser a seção 8. O texto foi reconstruído em LaTeX a partir do PDF fornecido.
