# Complemento do original de 77 páginas

Reproduz integralmente os enunciados e as demonstrações matemáticas dos
resultados 6.1, 6.2, 6.3 e 21.1 do original. A numeração é mantida para permitir
o cruzamento documental. Remissões externas foram adaptadas ao novo contexto.
Não se afirma que esses quatro resultados já tenham provas Lean.

O PDF recomposto tem três páginas. Para compor: `tectonic --keep-logs complemento.tex`
ou `latexmk -xelatex complemento.tex`. A bibliografia é a do original recebido.
