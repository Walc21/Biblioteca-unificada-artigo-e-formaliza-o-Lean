# Artigos 2 e 3 — Biblioteca determinística

Cada pasta contém um fonte LaTeX completo, referências e figuras PDF vetoriais. Execute `bash compilar.sh` dentro da pasta desejada; requer TeX Live com latexmk, pdfLaTeX e BibTeX.

Os programas e dados racionais originais estão em reproducibility/. Os scripts de verificação gravam tabelas nos caminhos do manuscrito de origem; para executá-los sem alterar os artigos, use um diretório separado como --output-root. Os fontes finais incorporam as tabelas, portanto a compilação não depende de executar os experimentos.

A revisão mantém os enunciados e demonstrações. Atualiza a composição, os vínculos entre resultados e a precisão da descrição da etapa de Cantor e do oráculo de comparação exata.
